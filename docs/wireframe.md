# 와이어프레임 (텍스트 스케치)

> 5주차 실습: "마이링크 메인 화면 와이어프레임을 텍스트로 그려줘"

## 1. 개인 공개 페이지 `/username` (모바일 360px)

```
┌──────────────────────────────┐
│ [🔗]   마이페이지  학습기록  [로그인] │  ← 헤더
├──────────────────────────────┤
│                              │
│            ( 지 )            │  ← 원형 아바타 96px
│             지연              │  ← displayName
│          @jiyeon1117          │  ← username
│   바이브 코딩으로 만든 링크 모음    │  ← bio
│                              │
│  ┌────────────────────────┐  │
│  │ GitHub               ↗ │  │  ← 링크 버튼 (클릭 → 새 탭 + 카운트 +1)
│  └────────────────────────┘  │
│  ┌────────────────────────┐  │
│  │ 인스타그램            ↗ │  │
│  └────────────────────────┘  │
│  ┌────────────────────────┐  │
│  │ 유튜브               ↗ │  │
│  └────────────────────────┘  │
│                              │
│     마이링크로 나만의 페이지 만들기   │
└──────────────────────────────┘
```

## 2. 마이페이지 `/mypage` (데스크탑 1024px)

```
┌───────────────────────────────────────────────────────────┐
│ [🔗 마이링크]          마이페이지  학습기록      지연님 [로그아웃] │
├───────────────────────────────────────────────────────────┤
│ 내 링크 관리                                        [새로고침] │  ← 상단: 제목
│ ┌───────────────────────────────────────────────────────┐ │
│ │ 프로필 수정            공유 주소: /jiyeon1117           │ │
│ │ [username      ]  [displayName    ]                   │ │
│ │ [bio                                       ]  [저장]  │ │
│ └───────────────────────────────────────────────────────┘ │
│ ┌──────────────────────┐ ┌──────────────────────────────┐ │
│ │ 링크 추가             │ │ 내 링크 목록                  │ │  ← 중간: 폼 / 하단: 목록
│ │ 제목 [            ]   │ │ GitHub   github.com/... [✏][🗑]│ │
│ │ 주소 [            ]   │ │ 블로그   blog.naver...  [✏][🗑]│ │
│ │ [      + 추가      ]  │ │                              │ │
│ └──────────────────────┘ └──────────────────────────────┘ │
│ ┌───────────────────────────────────────────────────────┐ │
│ │ 클릭 통계                                              │ │
│ │ ┏━━━━━━━━━━━━━━━━━┓                                    │ │
│ │ ┃ 총 234 클릭       ┃                                    │ │
│ │ ┗━━━━━━━━━━━━━━━━━┛                                    │ │

│ │ 3. Blog      ██████               44 클릭               │ │
│ └───────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────┘
```
