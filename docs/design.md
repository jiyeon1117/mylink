# 디자인 문서

> 4주차 좋은 프롬프트(네오브루탈리즘) 기준. 13주차 통계 UI도 이 문서의 색상·글꼴·간격을 따른다.

## 스타일: 네오브루탈리즘 (Neo-Brutalism)

- 굵은 검은 테두리 **3px**
- 굵은 그림자 `4px 4px 0 #111` (hover 시 `6px 6px`, 클릭 시 그림자 없음)
- 레트로한 웹 느낌, 평평한 원색

## 색상

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| background | `#FFF3B0` | 밝은 노란색 배경 |
| surface | `#FFFFFF` | 카드 |
| primary | `#5B5FC7` | 주요 버튼 (7주차 보라색) |
| pink | `#FF8FAB` | 강조, 삭제 버튼 |
| mint | `#7EE2B8` | 알림 띠, 통계 막대 |
| sky | `#8ECDF7` | 아바타, 안내 카드 |
| danger | `#EF4444` | 에러 메시지 |

## 글꼴

- Pretendard Variable (한글), 제목은 800~900 굵기

## 간격 · 모양

- 카드 모서리 16px, 버튼·입력 칸 모서리 12px
- 카드 안쪽 여백 20px(모바일) / 24px(태블릿 이상)
- 화면 좌우 여백 16px, 최대 너비 1024px

## 반응형 breakpoint

| 화면 | 너비 | 배치 |
| --- | --- | --- |
| 모바일 | 360px~ | 1열 |
| 태블릿 | 768px~ | 2열 (홈: 프로필 / 링크) |
| 데스크탑 | 1024px~ | 마이페이지 폼·목록 2열 |
