# 사용자 시나리오

> 5주차 실습: 사용자 관점에서 흐름 설계 → 빠진 기능 발견

## 페르소나

**지연 (22세, 개발자 겸 대학생)** — 인스타그램 프로필에 GitHub, 블로그, 유튜브를 모두 알리고 싶다.

**방문자 민수** — 지연의 인스타 프로필 링크를 눌러 들어온 친구.

## 시나리오 1. 처음 가입하고 링크 등록하기 (지연)

1. 마이링크 홈에 들어온다.
2. 헤더의 **Google로 로그인** 버튼을 누르고 구글 팝업에서 계정을 고른다.
3. 헤더에 "지연님"과 **로그아웃** 버튼이 보인다.
4. **마이페이지**로 이동하면 username이 이메일 앞부분으로 자동 생성되어 있다.
5. 링크 추가 폼에 `GitHub` / `github.com/jiyeon1117`을 입력하고 **추가**를 누른다.
6. 목록에 바로 나타나고 입력 칸이 비워진다.
7. 새로고침해도 링크가 그대로 남아 있다.

→ 발견한 빠진 기능: 주소에 `https://`를 빼먹는 경우가 많음 → 자동으로 붙여주기

## 시나리오 2. 링크 수정·삭제하기 (지연)

1. 블로그 주소가 바뀌어서 연필 버튼을 누른다.
2. 제목·주소가 입력 칸으로 바뀌고 기존 값이 채워져 있다.
3. 주소를 고치고 **저장**을 누른다. (실수로 지우면 **취소**로 원래 값 복구)
4. 더 이상 안 쓰는 링크의 휴지통 버튼을 누른다.
5. "정말 삭제하시겠습니까?" 모달에서 **삭제하기**를 누른다.

→ 발견한 빠진 기능: 실수 방지용 삭제 확인 모달

## 시나리오 3. 공유 주소 정하고 공유하기 (지연)

1. 마이페이지의 프로필 수정에서 username을 `jiyeon1117`로 바꾼다.
2. 이미 누가 쓰는 이름이면 "이미 사용 중인 username이에요" 에러가 뜬다.
3. 저장 후 `/jiyeon1117` 주소를 인스타그램 프로필에 붙여 넣는다.

## 시나리오 4. 방문해서 링크 누르기 (민수)

1. 지연의 인스타그램에서 `/jiyeon1117` 링크를 누른다.
2. 로그인하지 않아도 지연의 프로필과 링크 버튼들이 보인다.
3. GitHub 버튼을 누르면 새 탭으로 열린다.
4. 없는 username으로 들어가면 404 화면이 보인다.

## 시나리오 5. 통계 확인하기 (지연)

1. 마이페이지 하단 **클릭 통계**에서 "총 27 클릭"을 확인한다.
2. 링크별 클릭 수가 많은 순으로 정렬되어 있어 GitHub이 가장 인기 있다는 걸 안다.
